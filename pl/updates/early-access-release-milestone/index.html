Kolejny etap Early Access zakończony

All-G StockMate 0.9.0-ea.5 został opublikowany jako GitHub Pre-release, zamykając kolejny istotny etap procesu wydawniczego Early Access.

To wydanie przeprowadza aktualny build Early Access przez pełną ścieżkę publikacji. Weryfikację wydania przeszły zarówno build Windows, jak i Android. Pakiet APK dla Androida został prawidłowo podpisany i zweryfikowany na rzeczywistym urządzeniu, a artefakty wydania wraz z ich sumami SHA-256 zostały sprawdzone przed publikacją.

Od buildu do opublikowanego wydania

Tag wydania wskazuje na zweryfikowany baseline kodu źródłowego, materiały umożliwiające odzyskanie klucza wydania zostały bezpiecznie zarchiwizowane, a finalne artefakty opublikowano wraz z manifestem sum kontrolnych.

Repozytorium pozostało czyste przez cały proces publikacji, a chroniony baseline nie został zmieniony.

Co oznacza to wydanie?

Wersja 0.9.0-ea.5 nadal jest wydaniem Early Access. Jest już dostępna do zewnętrznych testów EA, ale nie należy jej traktować jako ukończonego wydania produkcyjnego.

Przed nami pozostają m.in. dalsze dopracowanie Androida, szerszy etap prac nad UX/UI oraz funkcje przewidziane dla kolejnych etapów rozwoju.

Jawnie pozostawiamy również dwa ograniczenia techniczne: plik wykonywalny Windows nie jest jeszcze podpisany za pomocą Authenticode, a pełny test Windows na całkowicie czystym środowisku, z wykorzystaniem odizolowanej maszyny wirtualnej lub Windows Sandbox, nie został jeszcze przeprowadzony.

Żaden z tych punktów nie blokuje obecnego Early Access, ale oba pozostają na liście dalszych prac.
