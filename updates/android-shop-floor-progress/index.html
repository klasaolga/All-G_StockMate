StockMate Standard: Android moves closer to everyday shop-floor work

Stock management doesn’t happen only behind a desk. It happens between shelves, during deliveries, while checking products, and when counting stock. That’s why we’re continuing to expand All-G StockMate’s Android application, bringing more everyday inventory operations into a mobile workflow.

Recent development has moved beyond basic connectivity and product lookup. We’re integrating and testing more of the operations that make a mobile inventory application genuinely useful in a small shop.

More than a barcode scanner

The goal for StockMate on Android is not simply to scan a barcode and send the result to a computer. We’re building a full mobile client designed to support the inventory tasks available in each StockMate edition, with an interface suited to working on a phone.

Recent work has expanded the foundations for managing products and carrying out stocktakes. This includes further integration of operations on counted inventory items and safeguards that help keep mobile actions consistent with the main inventory system. These are meaningful development milestones, although not every operation has a finished user interface yet.

The practical goal is straightforward: make it easier to check information, work with products, and carry out stocktakes where the stock actually is.

One inventory system. Two ways to work.

StockMate follows an offline-first approach. The Windows application remains the central local system, while the Android client is being developed to communicate with it over a local Wi-Fi network.

Both applications are intended to work with the same authoritative inventory data, rather than maintaining separate, potentially conflicting stock records. This means the shop’s everyday inventory workflow does not need to depend on a cloud account or a continuously available internet connection.

The aim is to combine the convenience of mobile work with the control of a locally managed inventory system.

Reliability matters as much as convenience

A mobile inventory application needs to handle more than successful operations. What happens if a connection drops while an action is being processed? What if the application closes unexpectedly? How can the system distinguish between an operation that failed and one that may already have changed the inventory?

These questions are part of our current development work. We’re extending the mechanisms that protect inventory operations and working on persistent recovery records that will help the application handle interrupted or uncertain actions more safely.

This recovery work is still undergoing implementation and validation. It is not yet a completed, publicly available feature. Our priority remains the same: inventory data should be predictable and trustworthy, including when something goes wrong.

What’s available today, and what comes next?

All-G StockMate Early Access Free is already available for Windows. It provides local inventory management for small shops, including products, stock levels, deliveries, batches, expiry dates, stock movements, stocktaking, and CSV import and export.

StockMate Standard and the Android application remain in active development. The next stages include completing remaining mobile workflows, improving recovery from interrupted operations, refining the user interface, and carrying out further testing before public distribution. The broader roadmap also includes an Android client for the Free edition, within its own feature scope.

The Android application is not yet publicly available through Google Play. We are not announcing a release date at this stage.

We’re building StockMate for the realities of small retail: practical workflows, clear information, and stock records that people can rely on.
