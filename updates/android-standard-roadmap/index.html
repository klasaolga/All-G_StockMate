What the Android companion is meant to help with

The idea is not “turn everything into a phone app.” The idea is to make the phone useful where it makes real sense.

  • Product lookup and quick stock checks.
  • Barcode scanning.
  • Mobile product creation and editing.
  • Invoice photo capture and upload.
  • OCR-assisted invoice review.
  • Creating deliveries from reviewed invoice data.

What it is not

This stage is not planned as a cloud-first system. It is a secure local companion, not a remote access app in disguise.

Why later, not now

Mobile features are only worth adding when the core stock logic is solid. So yes, Android is important. No, it does not get to cut the queue.

This is a roadmap update, not a release announcement. Details can still change as the product evolves.
