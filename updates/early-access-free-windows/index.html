Early Access Free is available for Windows

StockMate Early Access Free is live on Windows. It is local, simple, and does not ask for an account.

Local-first setup

No cloud account is needed. The data stays on the Windows device.

  1. 1 Download Install the Windows package.
  2. 2 Use locally Run StockMate on your device, without signing in.
  3. 3 Send feedback later An optional local prompt can appear after 30 days.

What you get

This first public version focuses on the practical daily stuff: products, deliveries, batches, expiry dates, stock levels, stock movements, stocktaking, imports, and exports.

  • Up to 2,500 products.
  • Deliveries and batches.
  • Expiry-date tracking.
  • Stock movements and stocktaking.
  • CSV import and export.
  • Settings and local backups.

What it does not do yet

This is still the lean version. Mobile tools, invoice photos, OCR review, cloud accounts, remote access, and broader multi-location work come later.

Why we released it this way

The goal is simple: make the core stock workflow useful first. Fancy extras are nice, but reliable basics win the daily fight.
