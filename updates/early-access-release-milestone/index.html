Release 27 Sep 2026

Another Early Access milestone completed

All-G StockMate 0.9.0-ea.5 has been published as a GitHub Pre-release, completing another important stage in the project’s Early Access release process.

This release brings the current Early Access build through the complete publication path. Both the Windows and Android builds have completed their release verification. The Android APK was successfully signed and verified on real hardware, while release artifacts and their SHA-256 checksums were validated before publication.

From build to published release

The release tag points to the verified source baseline, the release-key recovery materials have been securely backed up, and the final artifacts have been published together with their checksum manifest.

The repository remained clean throughout the publication process and the protected baseline was left unchanged.

What this release means

Version 0.9.0-ea.5 remains an Early Access release. It is now available for external EA testing, but it should not be confused with a finished production release.

There is still work ahead, including further Android refinement, the broader UX/UI pass, and features planned for subsequent development stages.

Two technical limitations also remain explicit in this release: the Windows executable is not yet Authenticode-signed, and a true clean-machine Windows smoke test using an isolated VM or Sandbox environment has not yet been completed.

Neither blocks this Early Access release, but both remain part of the work ahead.
